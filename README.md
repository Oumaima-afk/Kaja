# Kaja 🗓️

> Application mobile de gestion et d'organisation de sorties entre amis.

---

## À propos du projet

Kaja est un projet personnel en cours de développement.  
L'idée est simple : faciliter l'organisation de sorties entre amis — proposer des activités, voter, valider une date, le tout au même endroit.

Ce projet est aussi l'occasion pour moi de monter en compétences sur **React Native**, tout en consolidant mes pratiques sur **NestJS** côté back-end.
